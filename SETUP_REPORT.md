## Улучшения безопасности

### До исправлений:
```c
// УЯЗВИМОСТЬ: Crash если файл не существует

fseek(f, 0, SEEK_END);  // NULL pointer dereference!
```

### После исправлений:
```c
FILE* f = fopen(filename, "rb");
if (!f) {
    fprintf(stderr, "Error: Cannot open file '%s'\n", filename);
    return NULL;
}
if (fseek(f, 0, SEEK_END) != 0) {
    fprintf(stderr, "Error: Cannot seek in file '%s'\n", filename);
    fclose(f);
    return NULL;
}
```

### До исправлений:
```c
// УЯЗВИМОСТЬ: Out-of-bounds write
u32 num = train_labels_file->data[i];

```

### После исправлений:
```c
u32 num = (u32)train_labels_file->data[i];
if (num >= 10) {
    fprintf(stderr, "Error: Invalid label %u at index %u\n", num, i);
```

## Модель нейронной сети

```
Input (784) → W0×x+b0 → ReLU → a0 (16)
                                 ↓
                          W1×a0+b1 → ReLU → z1 (16)
                                 ↓           ↓
                            a1 = a0 + z1 (residual)
                                 ↓
                          W2×a1+b2 → Softmax → Output (10)
```

**Параметры:**
- Слоёв: 3 (2 скрытых + выходной)
- Параметров: W0(16×784) + W1(16×16) + W2(10×16) + biases = ~13K параметров
- Инициализация: Xavier-like
- Оптимизатор: SGD
- Функция потерь: Cross-entropy

**Ожидаемая точность:** 86-89% на тестовом наборе MNIST

### Краткое содержание видео: Создание библиотеки машинного обучения с нуля для распознавания рукописных цифр (EMNIST)

---

### Введение и основные компоненты машинного обучения

- Машинное обучение сводится к созданию модели — функции с настраиваемыми параметрами, которая отображает входные данные в выходные.
- В основе ML-фреймворка лежат **три ключевых компонента**:
  - **Математический слой для работы с тензорами** (в данном случае — матрицами).
  - **Автоматическое вычисление градиентов** для произвольных функций.
  - **Связывающий слой (glue layer)**, который организует обучение, вычисляя градиенты и обновляя параметры.

---

### Математический слой: работа с матрицами

- Используются **матрицы как частный случай тензоров** (вместо работы с тензорами произвольной размерности).
- Реализованы базовые операции:
  - Создание, копирование, очистка матриц.
  - Арифметические операции: сложение, вычитание, масштабирование, умножение матриц с опциями транспонирования и нулевого результата.
  - Функции активации: **ReLU** (Rectified Linear Unit) и **softmax**.
  - Функция потерь: **кросс-энтропия** для работы с вероятностными распределениями.
- Для каждой функции реализованы также вычисления её градиентов — необходимы для обратного распространения ошибки.

---

### Загрузка и подготовка данных EMNIST

- Используется Python-скрипт с библиотекой **TensorFlow Datasets** для загрузки и преобразования EMNIST в numpy-массивы.
- Изображения нормализуются (значения пикселей переводятся из диапазона 0–255 в 0–1).
- Метки классов преобразуются в формат **one-hot encoding** — вектор с единицей в позиции правильного класса и нулями в остальных.
- Далее данные сохраняются в бинарные файлы, которые загружаются в C-программе.

---

### Построение вычислительного графа и автоматическое дифференцирование

- Модель представлена в виде **вычислительного графа**, где узлы — переменные с матричными значениями, а рёбра — операции.
- Для вычисления градиентов используется метод **обратного распространения ошибки (reverse-mode automatic differentiation)**.
- Вся модель и операции описываются через структуру `model_var`, которая содержит:
  - Значение, градиент, индекс, тип операции, флаги (например, требует ли переменная градиента).
- Для компиляции модели реализован **топологический сортинг** графа (по алгоритму поиска в глубину), чтобы определить порядок вычислений.
- Есть два "программы" — **прямая (forward)** и **обратная (backward)**, которые последовательно вычисляют значения и градиенты.

---

### Реализация обратного распространения градиентов

- Для каждого типа операции реализована функция вычисления градиента.
- Обратный проход проходит по вычисленному топологическому порядку в обратном направлении, накапливая градиенты.
- Пример:
  - Для сложения градиенты просто распространяются к входам.
  - Для умножения матриц используются транспонирование и умножение для вычисления градиентов по параметрам.
  - Для softmax вычисляется полный якобиан и перемножается с градиентом.
  - Для ReLU учитывается производная (градиент равен 1 для положительных элементов, 0 — для отрицательных).

---

### Архитектура модели для EMNIST

- Модель — простая нейронная сеть (перцептрон) с тремя слоями:
  - Вход: 784 признака (28x28 пикселей).
  - Первый скрытый слой: 16 нейронов + ReLU.
  - Второй скрытый слой: 16 нейронов с residual connection.
  - Выход: 10 нейронов с softmax (вероятности для цифр 0–9).
- Параметры инициализируются случайными значениями по методу, похожему на **Xavier initialization**.
- Потери считаются функцией кросс-энтропии.

---

### Обучение модели

- Используется базовый метод **стохастического градиентного спуска (SGD)**:
  - Данные разбиваются на батчи.
  - Для каждого батча вычисляются градиенты и усредняются.
  - Параметры обновляются с учётом learning rate.
- В начале каждой эпохи порядок данных перемешивается.
- После каждой эпохи выводится среднее значение функции потерь.
- По окончании обучения проводится тестирование с подсчётом точности (accuracy) — сравнение предсказаний с истинными метками.

---

### Результаты и выводы

- После нескольких эпох обучения модель достигает примерно **86–89% точности** на тестовом наборе.
- Демонстрируется работа модели на конкретном примере рукописной цифры: до обучения выходные вероятности были равномерными, после обучения — явно выделяется правильный класс.
- Подчёркнута эффективность подхода с вычислительным графом и автоматическим дифференцированием для реализации сложных моделей, включая residual connections.
- Вся реализация сделана на языке C с использованием арен для управления памятью, что упрощает выделение и очистку ресурсов.

### Ключевые термины и определения

| Термин                                 | Определение                                                                              |
| -------------------------------------- | ---------------------------------------------------------------------------------------- |
| Тензор                                 | Многомерный массив чисел, в данном случае — матрицы                                      |
| ReLU                                   | Rectified Linear Unit — активационная функция: max(0, x)                                 |
| Softmax                                | Функция, преобразующая вектор в вероятностное распределение                              |
| Кросс-энтропия                         | Функция потерь для сравнения вероятностных распределений                                 |
| Обратное распространение               | Алгоритм вычисления градиентов для обучения нейросети                                    |
| Топологический сортинг                 | Упорядочивание узлов графа так, чтобы зависимости вычислялись раньше зависимых элементов |
| SGD (стохастический градиентный спуск) | Метод оптимизации с обновлением параметров по батчам и усреднением градиентов            |

### Итог

Видео подробно разбирает процесс создания собственной библиотеки машинного обучения на C, начиная с низкоуровневой работы с матрицами и заканчивая построением вычислительного графа и обучением модели на данных EMNIST. **Ключевым достижением является реализация обратного распространения через вычислительный граф, что позволяет строить и обучать сложные модели с произвольными архитектурами, включая residual connections.** Практическая демонстрация показывает успешное обучение модели с высокой точностью распознавания рукописных цифр.
